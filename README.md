# Property Post Maker

A production-quality React web application to instantly generate real-estate social media posts.

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### How to run locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

### Environment Variables
This project requires **NO** environment variables to run.

## Tech Stack
- React
- Vite
- Tailwind CSS v4
- html-to-image (for PNG export)
- Lucide React (for icons)
